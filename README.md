# Incident Reporting Activity — Student Version

This GitHub-ready version contains six group cases and fillable worksheets. It does **not** contain the model answers.

## Student features

- Six new incident-reporting cases
- Fields for section, group number, names of members, and date completed
- Five short worksheet questions aligned with the lecture
- Responses saved automatically in the browser
- Completed worksheet downloaded as a PDF
- Built-in upbeat background music with an On/Off control
- Responsive layout for phones, tablets, laptops, and classroom projectors

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The activity uses no external packages, audio files, or accounts. Browsers require the user to click **Music Off** before audio can begin.
