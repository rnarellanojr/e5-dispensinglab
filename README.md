# Incident Reporting Activity — Answer-Key Version

This GitHub-ready version contains the same six group cases and fillable worksheets as the student version. Each case includes a freely accessible **View model answers** button.

## Instructor features

- Model incident classification and first response priority
- Sample facts, contributing condition, preventive action, and verification check
- Fields for section, group number, names of members, and date completed
- Responses saved automatically in the browser
- Completed worksheet downloaded as a PDF
- Built-in upbeat background music with an On/Off control

## Publish with GitHub Pages

1. Create a separate GitHub repository for this version.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

Keep this repository separate from the student repository if students should not access the model answers.

The music is generated inside the webpage and requires the user to click **Music Off** before it begins.
